# Algo Notes — асимптотика алгоритмов

Небольшой адаптивный сайт-конспект на русском языке: HTML, CSS и JavaScript без сборщика и сторонних библиотек.

## Запуск локально

1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Для более близкого к серверному запуску можно использовать Python:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на Render (Static Site)

1. Загрузите эти файлы в корень нового GitHub-репозитория.
2. Войдите в Render и нажмите **New + → Static Site**.
3. Подключите GitHub-репозиторий.
4. Укажите настройки:
   - **Branch:** `main` (или ваша основная ветка)
   - **Build Command:** оставить пустым
   - **Publish Directory:** `.`
5. Нажмите **Create Static Site**. Render соберёт и опубликует сайт; после этого выдаст публичный URL.

## Содержимое

- `index.html` — разметка и материал конспекта.
- `styles.css` — оформление, адаптивная верстка и светлая тема.
- `script.js` — интерактивные карточки сложностей, переключение примеров, копирование кода и мини-тест.

Сайт статический: сервер, база данных и API-ключи не требуются. Google Fonts используются как внешний шрифт; если он недоступен, применится системный шрифт.
