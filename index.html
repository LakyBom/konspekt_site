01 / ОСНОВЫ

Что такое асимптотика?

Мы оцениваем, как меняется потребление ресурсов при увеличении входа.

⏱

Временная сложность

Описывает, как растёт число элементарных операций алгоритма. Это не измерение секунд.

Например: O(n) — линейный рост
▦

Пространственная сложность

Описывает, как растёт дополнительная память, нужная алгоритму, в зависимости от размера входа.

Например: O(1) — постоянная память
i

Big O обычно описывает верхнюю асимптотическую границу. В учебных задачах его часто используют для обозначения порядка роста в худшем случае. Константы и менее значимые слагаемые отбрасывают: 3n² + 5n + 7 = O(n²).

03 / АНАЛИЗ ЦИКЛОВ

Как считать сложность

Сначала считаем итерации, затем упрощаем выражение.

1

Найди число итераций

Посмотри на условие остановки и изменение счётчика.

2

Оцени работу внутри

Если тело выполняет O(1), то стоимость цикла определяется числом итераций.

3

Запиши формулу

Последовательные циклы складываются, вложенные — часто перемножаются или суммируются.

4

Оставь главный член

Удали константы и менее быстро растущие слагаемые.

Постоянное число повторовO(1)
for i in range(5):
    do_constant_work()

Пять итераций — это константа, даже если вход огромный.

Шаг на постоянную величинуO(n)
for i in range(0, n, 3):
    do_constant_work()

Примерно n/3 итераций. Константа 1/3 не меняет класс.

Умножение счётчикаO(log n)
i = 1
while i < n:
    i *= 2

После k итераций i = 2ᵏ. До n нужно около log₂(n) шагов.

Вложенные циклыO(n²)
for i in range(n):
    for j in range(n):
        do_constant_work()

n итераций снаружи × n внутри = n² операций.

Вложенный цикл с меняющейся границейO(n²)
for i in range(n):
    for j in range(i):
        do_constant_work()

Общее число шагов: 0 + 1 + 2 + … + (n − 1) = n(n − 1)/2 = O(n²).

ПОИСК ЭЛЕМЕНТА

Линейный поиск

Последовательно проверяем элементы, пока не найдём цель или не закончим список.

Лучший случайO(1)
Худший случайO(n)
✓

Если цель стоит первой, выполняется одно сравнение.

example.py
def search(arr, target):
    for i, value in enumerate(arr):
        if value == target:
            return i
    return -1

print(search([1, 10, 30, 15], 30))  # 2

05 / ПРАВИЛА

Как объединять сложности

＋

Последовательные блоки

Сложности складываем, затем оставляем доминирующий член.

O(n) + O(n²) = O(n²)
×

Вложенные циклы

Если оба цикла выполняются n раз и работа внутри постоянная, число операций перемножается.

n × n = O(n²)
Σ

Меняющаяся граница

Суммируем число итераций внутреннего цикла для каждого шага внешнего.

1 + 2 + … + n = O(n²)
06 / ПОВТОРЕНИЕ

Шпаргалка

Короткие правила перед контрольной или собеседованием.

O(1)Константное число операций, независимо от n.Индекс массива
O(log n)На каждом шаге размер задачи уменьшается в несколько раз.Двоичный поиск
O(n)Один проход по n элементам.Линейный поиск
O(n log n)Логарифмическое число уровней с линейной работой на уровне.Merge sort
O(n²)Часто два полных вложенных прохода.Selection sort
O(2ⁿ)Перебор комбинаций, число которых экспоненциально растёт.Все подмножества
!

Важные уточнения. Линейный поиск: лучший случай O(1), худший O(n), средний обычно O(n) при стандартных предположениях. В задаче со специальной суммой чётная длина даёт O(1), нечётная — O(n); поэтому сложность зависит от рассматриваемого случая, а не от «среднего события». Сортировки выбором и вставками в общем случае имеют O(n²) времени.
